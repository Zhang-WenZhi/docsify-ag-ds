## 如何选择小程序 UI 框架？

以下是转换后的 Markdown 表格格式，便于复制后直接展示：  


| 场景                | 推荐框架                          | 理由                              |
|---------------------|-----------------------------------|-----------------------------------|
| 微信小程序基础项目  | WeUI 小程序版、ColorUI            | 轻量、风格贴合微信生态            |
| 电商/零售类小程序   | Vant Weapp、Taro UI               | 丰富的商品组件和跨端能力          |
| 中后台管理系统      | iView Weapp                       | 表格、表单等中后台组件完善        |
| 多端适配需求        | Uniapp + uView、Taro UI           | 一套代码适配多平台，效率高        |
| 视觉效果优先        | ColorUI、Flutter 方案              | 支持渐变、动效和复杂渲染          |

## 移动端开发技术(Android 和 iOS 两个平台)

```shell
1. 原生开发
2.跨平台技术:
根据其原理，主要分为三类：
    H5 + 原生（Cordova、Ionic、微信小程序）==> Hybrid技术,H5 + 原生 的开发模式为混合开发 
    JavaScript 开发 + 原生渲染 （React Native、Weex）
    自绘UI + 原生 (Qt for mobile、Flutter)
``` 


| 技术类型               | UI 渲染方式          | 性能   | 开发效率   | 动态化   | 框架代表                |
|------------------------|---------------------|--------|------------|----------|-------------------------|
| H5 + 原生              | WebView 渲染         | 一般   | 高         | 支持     | Cordova、Ionic          |
| JavaScript + 原生渲染  | 原生控件渲染        | 好     | 中         | 支持     | RN（React Native）、Weex |
| 自绘 UI + 原生         | 调用系统 API 渲染    | 好     | Flutter高，Qt低 | 默认不支持 | Qt、Flutter             |

```plaintext
1.环境准备：
# 安装 Node.js (推荐 v14+): https://nodejs.org
# 安装 Ionic CLI
npm install -g @ionic/cli
# 可选：安装 Cordova (如果需要访问原生功能)
npm install -g cordova

2. 创建新项目
# 创建新项目 (选择 Angular/React/Vue 框架)
ionic start ionic-angular-app-wenzhi tabs --type=angular

# 其他常用选项：
# --type=react   # 使用 React 框架
# --type=vue     # 使用 Vue 框架
# blank          # 空白模板
# sidemenu       # 侧边栏模板
# tabs           # 标签页模板

# 进入项目目录
cd ionic-angular-app-wenzhi

3.项目结构
ionic-angular-app-wenzhi/
├── src/                 # 源代码目录
│   ├── app/             # 主应用逻辑
│   ├── pages/           # 页面组件 (Angular/React/Vue)
│   ├── components/      # 共享组件
│   ├── services/        # 服务 (数据访问、API调用)
│   ├── assets/          # 静态资源 (图片、字体等)
│   ├── global.scss      # 全局样式
│   └── index.html       # 入口 HTML
├── ionic.config.json    # Ionic 配置
├── package.json         # 依赖和脚本
└── capacitor.config.ts  # Capacitor 配置 (原生功能)
```

```shell
ionic generate page home # home.page.html
# Ionic 框架内置了导航系统
# 使用 Capacitor 或 Cordova 访问原生设备功能：
npm install @capacitor/camera
npx cap sync # 同步插件到 iOS 和 Android 平台 # 错误

# 在浏览器中运行
ionic serve

# 在 iOS 模拟器中运行
ionic capacitor run ios --livereload

# 在 Android 模拟器中运行
ionic capacitor run android --livereload

# 构建 Web 版本
ionic build

# 添加 iOS 平台
ionic capacitor add ios
npx cap open ios  # 打开 Xcode 打包

# 添加 Android 平台
ionic capacitor add android
npx cap open android  # 打开 Android Studio 打包

```

```shell
  <config-file parent="/manifest" target="AndroidManifest.xml">
    <uses-permission android:name="android.permission.INTERNET" />
  </config-file>

cordova build android
生成的 APK 文件位于：platforms/android/app/build/outputs/apk/debug/app-debug.apk

cordova build ios
使用 Safari 的 Web Inspector 调试 iOS WebView：
Safari > 开发 > [你的设备] > [应用名称]
```
