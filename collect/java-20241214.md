```java
package com.example.demo.datastructure;

import java.util.PriorityQueue;
import java.util.Comparator;

public class Solution {
    public static void main(String[] args) {
        // 创建一个默认排序的优先队列
        PriorityQueue<Integer> naturalOrderQueue = new PriorityQueue<>();
        naturalOrderQueue.add(5);
        naturalOrderQueue.add(3);
        naturalOrderQueue.add(8);
        System.out.println("默认排序的优先队列: " + naturalOrderQueue);
        while (!naturalOrderQueue.isEmpty()) {
            System.out.println(naturalOrderQueue.poll());
        }

        // 创建一个自定义排序的优先队列
        PriorityQueue<Integer> customOrderQueue = new PriorityQueue<>(Comparator.reverseOrder());
        customOrderQueue.add(5);
        customOrderQueue.add(3);
        customOrderQueue.add(8);
        System.out.println("自定义排序的优先队列: " + customOrderQueue);
        while (!customOrderQueue.isEmpty()) {
            System.out.println(customOrderQueue.poll());
        }

        // 使用自定义对象和比较器
        PriorityQueue<Customer> customerQueue = new PriorityQueue<>(Comparator.comparingInt(Customer::getId));
        customerQueue.add(new Customer(3, "Alice"));
        customerQueue.add(new Customer(1, "Bob"));
        customerQueue.add(new Customer(2, "Charlie"));
        System.out.println("自定义对象排序的优先队列: " + customerQueue);
        while (!customerQueue.isEmpty()) {
            Customer customer = customerQueue.poll();
            System.out.println(customer);
        }
    }
}

    public int getId() {

    @Override

}
```

## OOP java 继承、多态、封装的区别

`继承`，在Java中，继承通过extends关键字实现。`Java只支持单继承`，即一个子类只能有一个父类。但可以`通过实现多个接口来实现类似多继承的效果`


`多态`是指同一个方法在不同的对象上表现出不同的行为。多态的实现依赖于`方法重写`和`向上转型`.
```markdown
多态的实现需要满足以下三个条件：
子类继承父类。
子类重写父类的方法。
父类引用指向子类对象
```

```java
// 继承、方法重写
class Animal {
public void makeSound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
@Override
public void makeSound() {
        System.out.println("Dog barks");
    }
}

// 向上转型(父类引用指向子类对象)
Animal myDog = new Dog();
myDog.makeSound(); // 输出 "Dog barks"
```

`封装`，它通过将`数据和操作数据的方法`捆绑在一起，隐藏对象的内部实现细节，只对外提供公共接口。这种机制有助于保护数据的`安全性`，提高代码的可`维护性`和`可重用性`。

总结来说：
`封装`关注的是隐藏实现细节，提供良好的访问和操作接口，提高代码的`安全性和可维护性`。
`继承`关注的是代码的`复用性和扩展性`，通过`子类继承父类`的属性和方法来实现。
`多态`关注的是同一行为在`不同对象`上的`不同表现形式`，通过`继承和方法重写`来`实现`。

## 重写、重载 区别 （观点1：重写和重载都是java实现多态性的方式; 观点2：重载是编译时的多态，即静态多态；实际开发中，重载常被视为多态的一部分）

方法重写（Overriding）和方法重载（Overloading）

`重写`（Override）和`重载`（Overload）是Java中两种不同的方法重写机制，它们之间的主要区别在于它们的作用范围和实现方式。

`重写`是指子类重新定义父类的方法，以实现子类的特定行为。重写要求子类和父类的方法具有相同的名称、参数列表和返回类型。重写的方法必须使用`@Override`注解进行标记，以确保编译器能够正确识别重写的方法。

```java
class Animal {
    public void makeSound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Dog barks");
    }
}
```

`重载`是指同一个类中定义`多个具有相同名称但参数列表不同的方法`。重载的方法可以有`不同的参数类型、参数数量和参数顺序`。重载的方法`不需要`使用`@Override`注解进行标记，因为它们是在`同一个类中定义`的。

```java
class Calculator {
    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }
}
```

总结来说，`重写和重载`都是Java中`实现多态性的方式`，但它们的`作用范围和实现方式`有所`不同`。重写用于子类重新定义父类的方法，而重载用于同一个类中定义多个具有相同名称但参数列表不同的方法。

关于`重载是否属于多态`，`存在不同的观点`。一些资料认为`重载是多态的一种表现形式`，因为重载允许一个类中有多个同名的方法，这些方法通过参数列表的不同来区分
。然而，也有`观点`认为`重载`是`编译时的多态，即静态多态`，而`多态`通常指的是`运行时的动态绑定，即动态多态`
。因此，严格来说，重载并不是多态的典型体现，因为重载是在编译期就已经确定调用哪个方法的，这称为“早绑定”或“静态绑定”。

尽管如此，`在实际开发中，重载常被视为多态的一部分`，因为它通过提供多种方法实现来增强代码的可读性和使用便捷性
。因此，在很多情况下，重载被视作一种实现多态的方式，尽管它不涉及运行时的动态绑定。

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) {
        this.val = val;
    }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
class SolutionTwo {
    // 二叉树的前序遍历
    public LinkedList<Integer> listPreorderTraversal(TreeNode root) {
        LinkedList<TreeNode> stack = new LinkedList<TreeNode>();
        LinkedList<Integer> output = new LinkedList<Integer>();
        if (root == null) {
            return output;
        }
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pollLast();
            output.add(node.val);
            if (node.right != null) {
                stack.add(node.right);
            }
            if (node.left != null) {
                stack.add(node.left);
            }
        }
        return output;
    }
}
```

## 单例模式、工厂模式和观察者模式

`单例模式（Singleton Pattern）`,这种模式适用于需要`全局唯一数据或功能模块`的场景，例如`日志记录、配置信息管理等`。
实现方式：
`饿汉式`：在`类加载时`就创建单例对象，适用于`线程安全要求不高`的场景。
`懒汉式`：在`第一次使用时`才创建单例对象，适用于`延迟加载和线程安全要求较高`的场景。
`双重检查锁`：结合了懒汉式和饿汉式的优点，既保证了`线程安全`，又实现了`延迟加载`。

`静态内部类实现`: 静态内部类实现单例模式的核心思想是`利用类加载机制`，延迟实例化单例对象，同时保证线程安全。

```java

      public static Singleton getInstance() {
          return INSTANCE;

  }
```

## TreeSet （红黑树存储元素）, 实现了SortedSet接口（实现了Set接口）, 有序, 自然顺序排序/自定义比较器排序； HashSet（哈希表（HashMap）来存储元素,查找），TreeSet(排序); PriorityQueue

TreeSet是Java中的一个集合类，它实现了SortedSet接口，并使用树形结构（红黑树）来存储元素。TreeSet中的元素是有序的，默认按照自然顺序排序，也可以通过自定义的比较器来指定排序规则。

TreeSet的常用方法包括：

- add(E e)：向TreeSet中添加元素。
- remove(Object o)：从TreeSet中删除指定的元素。
- contains(Object o)：判断TreeSet中是否包含指定的元素。
- size()：返回TreeSet中元素的个数。
- first()：返回TreeSet中的第一个元素。
- last()：返回TreeSet中的最后一个元素。
- headSet(E toElement)：返回TreeSet中小于指定元素的子集。
- tailSet(E fromElement)：返回TreeSet中大于等于指定元素的子集。
- subSet(E fromElement, E toElement)：返回TreeSet中从fromElement（包含）到toElement（不包含）的子集。
- higher(E e)：返回TreeSet中大于指定元素的元素。
- lower(E e)：返回TreeSet中小于指定元素的元素。

TreeSet的常用应用场景包括：

- 对元素进行排序：TreeSet可以用来对元素进行排序，默认按照自然顺序排序，也可以通过自定义的比较器来指定排序规则。
- 去重：TreeSet可以用来对元素进行去重，因为TreeSet中的元素是有序的，所以重复的元素会被自动去除。

TreeSet 和 HashSet 的区别：

- `TreeSet`是`有序`的，`HashSet`是`无序`的。
- `TreeSet的元素必须实现Comparable接口`，或者提供一个`Comparator比较器`，而HashSet的元素不需要实现Comparable接口。
- TreeSet的查找、插入、删除操作的时间复杂度为O(log n)，而HashSet的时间复杂度为O(1)。

HashSet 的应用场景：
HashSet 是 Java 中的一种集合类，它实现了 Set 接口，并使用哈希表（HashMap）来存储元素。HashSet 是无序的，不允许存储重复的元素。

HashSet 的常用方法包括：

- add(E e)：向 HashSet 中添加元素。
- remove(Object o)：从 HashSet 中删除指定的元素。
- contains(Object o)：判断 HashSet 中是否包含指定的元素。
- size()：返回 HashSet 中元素的个数。

HashSet 的常用应用场景包括：
- 对元素进行去重：HashSet 可以用来对元素进行去重，因为 HashSet 中的元素是无序的，所以重复的元素会被自动去除。
- 需要快速查找元素的场景：由于 HashSet 使用哈希表来存储元素，所以它的查找速度非常快，适合需要快速查找元素的场景。

```java
// 延迟删除 + 有序集合 + 优先队列
class ExamRoom {
    int n;
    TreeSet<Integer> seats;
    PriorityQueue<int[]> pq;

    public ExamRoom(int n) {
        this.n = n;
        this.seats = new TreeSet<Integer>();
        this.pq = new PriorityQueue<int[]>((a, b) -> {
            int d1 = a[1] - a[0], d2 = b[1] - b[0];
            // Comparator does not return 0 for equal elements
            return d1 / 2 < d2 / 2 || (d1 / 2 == d2 / 2 && a[0] > b[0]) ? 1 : -1;
        });
    }

    public int seat() {
        if (seats.isEmpty()) {
            seats.add(0);
            return 0;
        }
        int left = seats.first(), right = n - 1 - seats.last();
        while (seats.size() >= 2) {
            int[] p = pq.peek();
            //assert p != null;
            // Unboxing of 'seats.higher(p)' may produce 'NullPointerException'
            if (seats.contains(p[0]) && seats.contains(p[1]) && seats.higher(p[0]) == p[1]) { // 不属于延迟删除的区间
                int d = p[1] - p[0];
                if (d / 2 < right || d / 2 <= left) { // 最左或最右的座位更优
                    break;
                }
                pq.poll();
                pq.offer(new int[]{p[0], p[0] + d / 2});
                pq.offer(new int[]{p[0] + d / 2, p[1]});
                seats.add(p[0] + d / 2);
                return p[0] + d / 2;
            }
            pq.poll(); // leave 函数中延迟删除的区间在此时删除
        }
        if (right > left) { // 最右的位置更优
            pq.offer(new int[]{seats.last(), n - 1});
            seats.add(n - 1);
            return n - 1;
        } else {
            pq.offer(new int[]{0, seats.first()});
            seats.add(0);
            return 0;
        }
    }

    public void leave(int p) {
        if (p != seats.first() && p != seats.last()) {
            // Unboxing of 'seats.higher(p)' may produce 'NullPointerException'
            int prev = seats.lower(p), next = seats.higher(p);
            pq.offer(new int[]{prev, next});
        }
        seats.remove(p);
    }
}
```
